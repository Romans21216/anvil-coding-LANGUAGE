# Bug Reporting and Triage

Report only reproducible defects as bugs. Include a minimal `.ANVL` source file, exact compiler/build steps, expected and observed behavior, platform, and relevant compiler/runtime version.

## Required issue names and label

- A defect confirmed by an independent Codex final-review critic is titled `Codex Bugs: <short description>` and carries the GitHub label `Codex Bugs`.
- A defect reported directly by repository owner `Romans21216` is titled `Romans21216-Bugs: <short description>` and carries the same `Codex Bugs` label.
- Missing roadmap features are tracked as planned work, not mislabeled as bugs.
- Do not open an unresolved issue for a defect that has already been fixed unless the defect still reproduces; preserve fixed regressions in automated tests.
